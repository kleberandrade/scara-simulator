Unity simulator for SCARA robot visualization and joint control.

## Getting started

- Clone the repository and add `.` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Assets/Scenes/Scara Demo.unity](https://github.com/kleberandrade/scara-simulator/blob/master/Assets/Scenes/Scara%20Demo.unity).

## Recorded requirements

- A Unity project is present, but its Editor version was not found in a tracked `ProjectVersion.txt`; inspect project provenance before choosing an Editor.
